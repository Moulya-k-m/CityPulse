# 🌆 CityPulse

### *Report urban problems. Help build a better city.*

CityPulse is a web-based civic reporting application that makes it simple for people to report everyday urban problems and bring attention to issues that affect their community.

From **garbage and waterlogging to damaged roads and street-light problems**, CityPulse allows users to create, manage, and organize reports through a simple and user-friendly web interface.

---

## ✨ What is CityPulse?

CityPulse provides a simple interface where users can:

📍 **Report an urban problem**  
📝 **Describe the issue**  
📷 **Upload an image of the problem**  
🏙️ **Specify its location**  
🔎 **Filter submitted reports**  
✏️ **Edit existing reports**  
🗑️ **Delete reports**

The project focuses on creating a simple way to document everyday urban issues and keep submitted reports organized.

---

## ⚡ Features

- 📝 Submit urban problem reports
- 🏷️ Select from different problem categories
- 📍 Add the problem location
- 📷 Upload an image with a report
- 🆔 Automatically generate a unique report ID
- 📅 Record the date and time of submission
- 🟡 Display report status
- 💾 Store reports using browser `localStorage`
- 🔎 Filter reports by problem type
- ✏️ Edit existing reports
- 🗑️ Delete reports
- 🔄 Keep reports available after refreshing the page
- 📱 Responsive and user-friendly interface

## 🔄 How It Works

1. Select the type of urban problem.
2. Enter a description of the issue.
3. Add the location.
4. Optionally upload an image.
5. Submit the report.
6. CityPulse generates a unique report ID and records the submission date.
7. The report appears in the **Community Reports** section.
8. Users can filter reports by problem type.
9. Users can edit or delete existing reports.
10. Reports remain available after refreshing the browser because they are stored locally.
